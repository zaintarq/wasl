Accessibility

Wasl should work for more people. We are not done yet.

Honest status of VoiceOver, larger text, contrast, and how to ask for help

Accessibility desk · September 2026 · zain.tariq@mail.com

✓
Wasl is 18+ only. Need help using the app? Email zain.tariq@mail.com.

What Wasl is

Wasl is an adults-only social app for iPhone: profiles, matching, private chat, clubs, and optional live video. This page is for App Store users, reviewers, and anyone who needs accessibility information.

Current support (this App Store version)

We have not yet completed Apple’s accessibility criteria for every common task (onboarding, settings, discovery, and chat). We do not currently claim full support for:

  • VoiceOver
  • Voice Control
  • Larger Text (Dynamic Type across all screens)
  • Dark Interface (the app is light-themed)
  • Differentiate Without Color Alone
  • Sufficient Contrast on every screen
  • Reduced Motion
  • Captions or Audio Descriptions for live video

Some buttons already have accessibility labels. System zoom and iOS accessibility settings still work at the OS level.

What we are adding next

A later update is planned to improve:

  • VoiceOver on signup, home, chat, and settings
  • Larger Text / Dynamic Type
  • Contrast and not relying on color alone
  • Reduced motion where we use animation
  • Captions where we can for recorded audio; live video remains optional

When those ship, we will update this page and the App Store accessibility listing.

Live video and audio

Live Random and club voice rooms are optional. They use camera and microphone only if you turn them on. We do not currently provide captions or audio descriptions for live sessions.

Request an accommodation

If a disability makes Wasl hard to use, email zain.tariq@mail.com with what you need. We will try to help or note it for the next update.
