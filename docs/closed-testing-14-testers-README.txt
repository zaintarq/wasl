CLOSED TESTING — 14 TESTER EMAIL CSV
====================================

File: closed-testing-14-testers.csv

HOW TO UPLOAD (Play Console)
------------------------------
1. Testing → Closed testing → Testers tab
2. Create email list (or open existing list)
3. Upload CSV → choose closed-testing-14-testers.csv
4. Save

CSV FORMAT (required by Google)
-------------------------------
- First row header must be exactly: Email address
- One Gmail / Google account per row
- UTF-8, .csv extension

IMPORTANT
---------
Each email must be a REAL Google account that can open the opt-in link.
Random/fake addresses in the CSV will not be able to install the test build.

Rows 1–2 are your real accounts. Rows 3–14 are placeholders — either:
  A) Replace each with a real teammate/friend Gmail before upload, OR
  B) Create 12 new Gmail accounts using those addresses (if still available)

You only need as many testers as you actually have; 14 is the max in this file.
Minimum for closed testing: 1 tester (yourself).

After upload, copy the opt-in URL and open it while signed into each tester Google account.
