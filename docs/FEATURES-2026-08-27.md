## Safety & Live

### Live Vision (Safe Search on camera)
- During random Live, the app periodically snapshots the **local PIP** (~5–7s).
- Cloud Function `moderateLiveFrame` runs Google Cloud Vision Safe Search (same adult/racy bar as photo uploads).
- On block: session ends (`endedReason: 'moderation'`), safety event `live_vision`, user alert, leave to idle (no rematch).
- Fail-open if Vision/network fails.
- **Needs new AAB** for client sampling; function already live.

### Shadowban + disable appeals
- `users.isShadowBanned` — hidden from discovery, user not told.
- Admin Users: Shadowban / Lift.
- Disabled accounts: in-app appeal gate → admin **Appeals** tab (approve / reject / shadowban instead).

## Privacy / Play trust

### Self-serve Delete account (stronger for Play)
- Settings → **Delete account now**
- Re-auth with password → type `DELETE` → callable `selfWipeAccount`
- Same wipe path as admin (Auth, profile, storage, Mehram, etc.) + confirmation email
- Requires recent login (`auth_time` ≤ 10 minutes)

### Admin queue still available
- **Ask admins to delete (queue)** / partial **Request data deletion**
- Auto-ack email on submit: “we got it, processing within 30 days”
- Admin **Deletions** desk: process wipe + OTP SMTP confirmation

### Wipe preview checklist
- Before **Delete data + email**, admin sees checklist of what will be removed (account vs partial).

### DSAR — Download my data
- Settings → **Download my data**
- Admin: **Export DSAR** on deletion cards + user directory
- Callable `exportUserDataPacket` → signed **JSON + ZIP** (7-day URLs) in Storage `dsar-exports/`

### Crash grouping
- Crashes fingerprint by stack → `crashGroups` with **×count**
- Admin Crashes tab: one card per stack (expand for sample); falls back to client-side group on recent logs

### Related earlier same day / prior commits in the privacy push
- In-app deletion requests + admin wipe + crash log desk
- Play-compliant delete-account page + correct `/wasl/` policy URLs
- Android versionCode **9** / `1.0.6` for closed testing (pre self-wipe / Live Vision client)

## Mehram

### Clearer invite UX
- Numbered steps (choose permission → share link)
- Checklist before sharing; stronger share copy (app-only link)
- Status: waiting for open vs **viewing now**
- Regenerate warns that the old link dies

### Session history for guardians (and girls)
- Visits recorded on invite open / leave / revoke / block
- Girl: **Supervision visits** in Mehram manage panel
- Guardian: **Session history** on supervision screen (this invite + on-device past opens)
- Callable `listMehramSessionHistory`
